# Sales & Revenue Analysis Dashboard

## Project Overview

An interactive Sales & Revenue Analysis Dashboard built using Microsoft Excel to analyze sales, profit, orders, customer segments, regions, product categories, shipping modes, and discount performance.

## Dataset

Superstore Sales Dataset

## Tools Used

- Microsoft Excel
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

## Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | ₹22,97,200.86 |
| Total Profit | ₹2,86,397.02 |
| Total Orders | 9,994 |
| Average Order Value | ₹229.86 |
| Profit Margin | 12.47% |

## Key Business Findings

1. Technology is the highest-selling category and also generates the highest profit.
2. West is the strongest region for both sales and profit.
3. Consumer is the strongest segment in both sales and profit.
4. Copiers are the top-profit sub-category.
5. Standard Class generates the highest sales and profit among shipping modes.
6. Discount levels need to be monitored to protect profitability.

## Business Recommendations

1. Focus inventory and marketing efforts on high-performing Technology products.
2. Study the West region's successful performance and replicate effective strategies.
3. Strengthen Consumer segment performance while improving Corporate and Home Office results.
4. Control excessive discounting to maintain healthy profit margins.
